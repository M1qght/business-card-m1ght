# About

Собираю визитку постепенно на HTML, CSS и JavaScript.
Сейчас есть [HTML-страница](index.html) с заголовком и ссылками, базовое
оформление карточки, кнопки и пиксельный шрифт.
Открыть её можно в браузере или через Live Server в VS Code.

## Базовое оформление

- `css/style.css` — цвета, расположение карточки и кнопок, hover ссылок.
- `fonts/Tiny5.ttf` — пиксельный шрифт с кириллицей, работает локально.
- `fonts/LICENSE.txt` — лицензия шрифта.

Карточка выровнена по центру через Flexbox, ссылки расположены столбиком.
Цвета вынесены в переменные `:root`. На узком экране отступы уменьшаются.
YouTube пока недоступен: ссылка на канал появится позже.

## К чему идём

- Пиксельная визитка со ссылками Telegram, GitHub и YouTube.
- Простая интерактивность главной страницы на знакомом JavaScript.
