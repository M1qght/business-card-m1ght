# О сайте

Собираю визитку о себе, используя знания HTML, CSS и JavaScript.
Имеется [HTML-страница](index.html) с заголовком и ссылками, присутствует [базовое оформление](css/style.css) в виде шрифта, расположения блоков и элементов, добавлен [JS](js/main.js)

## Базовое оформление

- `css/style.css` — цвета, расположение карточки и кнопок, hover ссылок.
- `fonts/Tiny5.ttf` — пиксельный шрифт с кириллицей, работает локально.
- `fonts/LICENSE.txt` — лицензия шрифта.

## Иконки, фон и JavaScript

- `images/` — пиксельные SVG-иконки сервисов.
- `js/main.js` — один обработчик клика и переключение палитры.
- `.theme-dawn` в CSS задаёт цвета рассвета вместо ночной палитры.
- `transition` делает hover плавнее, `@keyframes` двигает градиент.

## К чему идём

- Пиксельная визитка со ссылками Telegram, GitHub и YouTube.
- Простая интерактивность главной страницы на JavaScript.
