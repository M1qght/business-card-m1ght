# О сайте

Собираю визитку о себе, используя знания HTML, CSS и JavaScript.
Имеется [HTML-страница](index.html) с заголовком и ссылками, присутствует [базовое оформление](css/style.css) в виде шрифта, расположения блоков и элементов, добавлен [JS](js/main.js)

## Базовое оформление

- `css/style.css` — цвета, расположение карточки и кнопок, hover ссылок.
- `fonts/Tiny5.ttf` — пиксельный шрифт с кириллицей, работает локально.
- `fonts/LICENSE.txt` — лицензия шрифта.

## Краткое описание

- `images/` — пиксельные SVG-иконки сервисов.
- `js/main.js` — обработчики кликов, переключение палитры и кнопка описания.
- `.theme-dawn` в CSS задаёт цвета рассвета вместо ночной палитры.
- `transition` делает hover плавнее, `@keyframes` двигает градиент.
- `images/avatar.svg` — пиксельный аватар, также используется как иконка вкладки.
- Кнопка «Что я изучаю?» раскрывает и скрывает небольшое описание.
- Функция `showAbout` меняет текст кнопки и класс `hidden` через `if / else`.
- `games/crystal-quest/` — мини-игра, её оформление и JS лежат рядом.

## Мини-игра

[Поход за кристаллами](games/crystal-quest/index.html) — нужно победить трёх слизней и собрать пять кристаллов.
Есть обычный удар, щит и два зелья. Перед сильным ударом слизня появляется подсказка.
Правила можно раскрыть под кнопками игры.

В `game.js` объекты хранят здоровье и счётчики. Функции меняют эти данные после клика, а `renderGame` обновляет текст и полоски здоровья.
Для запуска достаточно открыть `index.html` в браузере и перейти в мини-игру.
